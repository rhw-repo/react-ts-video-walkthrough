# Video Walkthrough: Milestone 'Online Post Manager' (React in the MERN Stack)

## About

A single-page mini-site built to host a 2 min video walkthrough of a dashboard style app with React on the front-end. 

---

At this milestone, the app supports:

- **User authentication**

  - Sign up and log in flows  
  - Session-based protection of routes and data

- **User-scoped dashboard**

  - Each user sees only their own records  
  - CRUD operations on entries, with toast notifications on success/failure

- **Advanced filtering**

  - Global search across all fields  
  - Column-specific filters by text, tags, and date range  
  - Filters apply cumulatively in sequence
  ---

## Technologies & Tools

- **Frontend**  
  - React.js (Vite)  
  - TanStack Table v7  
  - UI components (with DOMPurify)  
  
- **Backend**  
  - Node.js + Express.js  
    - express-session  
    - express-validator  
    - Helmet  
    - CORS  
  - MongoDB (Mongoose)

- **Tooling & Utilities**  
  - ESLint & Prettier  
  - Postman  
  - Git & GitHub  
  - VS Code (Xubuntu & Windows)
